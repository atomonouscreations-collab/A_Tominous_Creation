# Funding / launch plan

No outside capital going in — funding this through open-source-native routes, in rough order of effort. Since this is more a software project than a hardware one, several of these (NLnet especially) are a better fit than they'd be for a pure hardware build.

## 1. Public build log (do this first — everything else depends on it)

- [ ] Create GitHub repo (public), push this scaffold
- [ ] Create hackaday.io project page
- [ ] First post: the concept + the "why open source, not patented" framing
- [ ] Post design updates as they happen, not just at milestones — reviewers and backers on every platform below are evaluating the log, not a pitch deck

## 2. Free exposure / prize money

- [ ] Enter the Hackaday Prize (world's largest open-source hardware competition, free to enter, cash prizes) once there's a real project page to point to

## 3. Grant funding (no company or degree required)

- [ ] NLnet NGI Zero Commons Fund — €5,000–50,000, open source eligible (hardware and software both), 6-question application. Framing angle: open software that enables distributed/access-open manufacturing (ties to the OpenMade mission) rather than a closed commercial machine — this fits especially well now that the core deliverable is software, not a physical product
- [ ] Check state/local innovation programs (Oklahoma: i2E, Tulsa Innovation Labs) for small grants or in-kind support

## 4. Audience-funded R&D

- [ ] GitHub Sponsors or Patreon tied to the build log once there's an audience worth asking
- [ ] Component sponsorships — reach out to toolchanger-adjacent vendors (hotend/extruder makers, filament brands) for parts in exchange for visibility, once the design is public enough to be worth sponsoring

## 5. Crowdfunding (later, once something is real)

- [ ] Crowd Supply — a hardware crowdfunding platform, so a weaker fit now that the core project is software; only worth it later if a standalone hardware piece (e.g. a tool-coupling kit) becomes worth selling on its own

## 6. Heavier-weight option

- [ ] SBIR/STTR (NSF/DOE) — non-dilutive, no degree required, needs a registered small business (BET 3-D or OpenMade LLC already qualify); heavier application, worth keeping in back pocket once there's a working prototype
