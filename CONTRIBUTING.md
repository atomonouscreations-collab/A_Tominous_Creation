# Contributing

This project is early — concept and design-doc stage, nothing built yet. Contributions welcome once the repo is public:

- Feedback and issues on the software design (see `docs/software.md`) — this is the actual project, so this is where contributions matter most
- Hardware feedback (see `docs/hardware.md`) — the base machine is a straightforward extension of an existing open design, so most hardware questions are really Voron community questions, not ones specific to this project
- Prior-art references — if you've seen this combination done before, open an issue, it helps keep the documentation honest
- Once software exists: testing against different machine configurations, since the whole point is that it needs to adapt to builds that don't look like any one reference machine
- Once hardware exists: build logs, part sourcing, firmware

All contributions to hardware designs are licensed under [CERN-OHL-S v2](hardware/LICENSE) unless stated otherwise. Software/firmware contributions are licensed under [GPLv3](LICENSE).
