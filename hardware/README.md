# hardware

Kept minimal on purpose — see `/docs/hardware.md`. The base machine is an extended-height Voron 2.4 with a simple arm mounted above it, sharing the same vertical linear rails. Motion and tool changing are already solved; this folder isn't meant to prescribe one correct way to build it.

- `mechanical/` — CAD source for the rail-height extension and arm mount, STEP/native files and exported STLs
- `electrical/` — schematics for whatever tool-coupling approach a build uses
- `bom/` — bill of materials per subsystem

Nothing here yet — design-doc stage, see `/docs/hardware.md` for the current concept.
